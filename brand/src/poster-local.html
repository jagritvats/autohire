On your disk

Your résumé, matches and drafts live in ~/.jobflow. They reach an AI model only if you connect one.

Free software

AGPL-3.0. Read it, change it, run your own copy. Serve a changed copy to others and you share the source.

Agent-ready

jobflow mcp lets an AI agent search your jobs and draft documents. Nothing it exposes fills or submits a form.

Quick start
$ git clone https://github.com/jagritvats/jobflow.git && cd jobflow
$ pnpm install && pnpm -r build
$ pnpm jobflow init && pnpm jobflow sync   # your résumé, then fetch and rank
$ pnpm jobflow serve                       # the web app on localhost:3000
